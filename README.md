# TFENN

TFENN is a typed covariant network built from invariant scalar gates and
offline-compiled intertwiners. Benzene pairs are the current development
benchmark; the compiler and network interfaces are intended for any supported
proper-rotation group supplied through generators.

Project shorthand `D6~` denotes the benzene proper rotational dihedral group
generated by a \(60^\circ\) rotation about the molecular normal and a
\(180^\circ\) rotation about an in-plane axis. Benzene group elements, Hom
dimensions, and covariant bases must not be hard-coded.

## Mathematical contract

- Use one root body frame for the complete input.
- Native covariant ingress is `x -> A` and
  `R -> PoseEncoder(R) -> r = {B^(s)}`. Raw pose does not enter through A.
- Symmetric lifts and registered intertwiner bases are frozen mathematical
  objects. Runtime learning acts on invariant Gate parameters and channel
  mixing.
- Declared same-TypeKey inputs may use concat-and-project bypass. Cross-TypeKey
  exchange must use a registered \(C\) path.
- The default coefficient output is signed and unbounded: the gamma head has
  identity output activation.
- TFENN layers use neither group convolution nor runtime group averaging.
  Group-averaged MLPs may be used only as explicitly labelled external
  baselines.

Network topology is not fixed. Every model must declare independently:

1. covariant flow: `STRICT_DECLARED_FLOW`, `EXPLICIT_REUSE_FLOW`, or
   `DENSE_HISTORY_FLOW`;
2. raw access: `STEM_ONLY_RAW`, `EXPLICIT_RAW_REREAD`, or `EVERY_STAGE_RAW`;
3. invariant context and enabled scalar families;
4. the enabled A-to-A, A-to-B, B-to-A, and B-to-B path signatures;
5. same-TypeKey bypass sources;
6. dense, diagonal, or factorized channel mixing;
7. Gate trunk and gamma-head design.

Strict flow is one available architecture, not a project-wide requirement.
Repeated use of an invariant scalar does not create a covariant edge.

## Canonical documentation

- `src/TFENN/MATH_NOTATION.MD`: global coordinate, type, flow, and naming
  conventions.
- `src/TFENN/MATH_NOTATION_2.md`: polynomial lifts, \(C\) bases, Gate heads,
  and channel mixing.
- `src/TFENN/AB_Covariant_Network_Design_Core.tex`: complete mathematical
  design, including A/B paths and direct A-head.
- `src/TFENN/AGENT.MD`: compact implementation and experiment-design contract.

## Repository layout

- `src/TFENN/tensor_math`: group-driven anchor, representation, lift, and
  intertwiner compilation plus differentiable runtime contractions.
- `src/TFENN/models`: configurable typed covariant networks.
- `src/TFENN/data`: dataset loading and generation.
- `experiments/benzene_pair`: executable benzene studies.
- `experiments/C`, `experiments/D`, and `experiments/E`: immutable completed
  experiment records.
- `tests`: compiler, covariance, model, data, and workflow tests.

Training protocols and launch commands belong to their experiment directory;
there is no single frozen default topology or study catalog.
