全部 31 个模型使用同一份 400000 样本数据、同一 Train Validation Test 划分、500 epoch、batch size 10000 和相同随机种子。结果均取 Validation normalized MSE 最低的 checkpoint。表中误差均为 relative RMSE percent。全部模型的 D6 协变性检查均通过。

## Concise summary

G00 的 Test relative RMSE 为 1.444124%。排除低容量 C29 与高容量 C30 后，C01 至 C28 中有 23 个模型在 Validation 和 Test 上同时优于 G00。约 20k 参数组按 Validation 排名时 C17 第一，C20 第二，对应 Validation relative RMSE 分别为 0.753518% 与 0.769125%；在 Test 上 C20 略优于 C17，对应 relative RMSE 分别为 0.759193% 与 0.764190%。C30 总体最佳，Test relative RMSE 为 0.471826%。

G00 每 epoch 中位耗时仅 0.464 秒。约 20k V2 模型的每 epoch 中位耗时为 6.606 秒，按未舍入的原始耗时计算约为 G00 的 14.23 倍。原因是 G00 将 144 个 D6×D6 群组合合并为一个大 batch，只运行少数大型 dense GEMM。V2 则逐 stage、逐 target、逐 path 执行大量小 Linear、einsum、basis contraction、concat、projection 与 running RMS，GPU kernel launch 和内存访问开销占主导。因此 144 个数学群作用不等于 144 次串行网络执行，可训练参数量也不等于实际计算量。

C17 与 C20 的共同信号是极窄 trunk 4、重复的 B 传播或 A 与 B 交织、以及靠近输出的 B1。C14 的 B only 深度模型也达到 0.920143%，而关闭 raw mixed 的 C22 明显退化到 2.007476%。这支持姿态条件耦合、多次 typed tensor 传播和 B 表征提炼比单纯扩大标量 trunk 更重要。由于这些模型不是严格单变量对照，该结论应视为下一轮消融实验的方向，而不是单一机制的因果证明。

C30 的参数量为 240746，约为 C17 的 12.07 倍。按当前编译清单统计，C30、C17 与 C20 的 compiled candidates 分别为 166、205 与 278，因此 C30 的优势并不来自更多的分支数量，更可能来自 width 32、A4 与 B4 channels，以及每条固定 basis path 上更丰富的系数函数。C30 的 Validation 与 Test 结果几乎一致，未显示测试集上的额外退化。这提示 400000 样本可以支持这一容量，也提示约 20k 参数模型仍处于容量受限区域。当前结果不能单独判断 C30 的优势来自 channels、trunk width 或总参数量，下一步应在相同拓扑上做分级容量与多 seed 对照。
